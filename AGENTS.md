# Agent instructions

Implement the requested outcome autonomously. Research uncertain technical
facts, prefer root-cause changes and verify every claim with executable
evidence.

This is a public product repository. Never add real tenant, repository, host,
network, credential or runtime-evidence data. Use synthetic `example-*`
identities and documentation address ranges. Public workflows must use standard
GitHub-hosted runners and must never route fork code to private capacity.

Blocking checks protect secrets, public/private separation, dependency
identity, state/schema integrity, one-job isolation and release provenance.
Formatting and generated artifacts should be repaired automatically.

Run `make verify` after changes. Preserve unrelated worktree changes.

Ordinary merge does not wait on a required general CI status check. The `Gate`
job still runs as truthful advisory evidence. Live GitHub settings are not
applied from this tree.

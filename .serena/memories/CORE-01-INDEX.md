# Index

What this repository is and where the durable knowledge about it lives.

Secure, disposable GitHub Actions capacity. Every job receives a fresh Incus/KVM
virtual machine that runs GitHub's official `actions/runner` exactly once,
exports its diagnostics, and is destroyed. This repository owns the policy,
admission, lifecycle and integration code around GARM and Incus. It does not
reimplement the Actions protocol.

## Rules that hold everywhere

- **Generated files carry a `GENERATED FILE` header and an `edit-source` list.**
  Change the named input and regenerate; editing the output detaches it from
  `.gds/bundle.lock.yaml`. `AGENTS.md` and `.claude/CLAUDE.md` are generated by
  the parent `gds` tool.
- **`config/*-audit.json` are records of observations, not desired state.** Some
  deliberately keep superseded values -- the account was renamed from
  `example-user` to `NDDev-OpenNetwork` and audit records keep the old locator on
  purpose. `internal/repositorycontract/identity_test.go` governs which paths
  may. Updating one to look current describes a run that never happened.
- **One statement per fact.** Where a version, digest, name or set appears twice,
  one of them is derived and a test holds it there. This is the repository's
  main recurring defect class; see `SUPPLY-01-ARTIFACTS` and `CACHE-01-NAMESPACE`
  for the two largest instances.
- **Verification:** `make verify`. It is the whole gate, and CI runs the same
  command rather than a subset.
